## 🌟 نظرة عامة

مشروع **Flowx 3D (فلوكس ثري دي)** يمثل قفزة نوعية في تفاعل الإنسان مع الفضاء الرقمي (Spatial Computing). تم بناؤه بأحدث تقنيات الويب العالمية لعام 2026: **Next.js 16** و **React 19** ومحرك الرسومات **Three.js** ونماذج الرؤية الحاسوبية العصبية **Google MediaPipe Vision**.

يتيح النظام لأي مصمم، مهندس، فنان، أو هاوٍ للطباعة ثلاثية الأبعاد أن يقف أمام كاميرا حاسوبه الشخصي ويبدأ بالرسم الحر في الفضاء، ليتحول مسار إصبعه في الهواء فوراً إلى مجسم ثلاثي الأبعاد ذي أبعاد هندسية حقيقية بالمليمتر، جاهز للإرسال إلى طابعات 3D Printers أو محركات الألعاب.

### 1. استوديو الرسم في الهواء (Air-Sketch Studio)
- **تتبع عصبي لـ 21 نقطة مفصلية**: يعتمد على نموذج MediaPipe Hand Landmarker المتطور، ويعمل محلياً داخل المتصفح عبر WASM بفضل معالجات كروت الشاشة GPU بدون رفع أي فيديو لسيرفر خارجي لضمان الخصوصية والسرعة المطلقة.
- **تنعيم المسارات الحسابية (Catmull-Rom Smoothing)**: خوارزمية ذكية تمتص ارتعاشات اليد الطبيعية وتحول النقاط الخام إلى منحنيات فائقة النعومة.
- **التصنيف الهندسي التلقائي للأشكال**: يتعرف المحرك على نية المستخدم ويحول رسمته إلى مجسمات منتظمة:
  - كرات (Spheres)، مكعبات (Cubes)، أسطوانات (Cylinders)، مخاريط (Cones)، حلقات (Tori).
  - مجسمات دورانية (Lathe Geometry) لتوليد المزهريات والكؤوس والزجاجات.
  - بثق المخططات الحرة (Outline Extrusions) للشعارات واللوحات.
  - حوامل ميكانيكية هندسية (L-Bracket).
  - تروس مسننة هندسية (Involute Gears).
  - جدران معمارية قائمة الزوايا (Architectural Walls).

### 2. مستعرض النماذج ثلاثية الأبعاد الاحترافي
- **دعم شامل للصيغ**: يدعم تشغيل `.glb`, `.gltf`, `.fbx`, `.obj` (مع مواد MTL), `.stl`, `.ply`, `.dae`.
- **مشغل حركات هيكلية كامل (Animation Timeline)**: التحكم في سرعة الحركة، التقديم، الإيقاف، واختيار المشاهد الحركية المتعددة.
- **أدوات المعاينة الهندسية**:
  - نمط الخطوط الهيكلية (Wireframe Mode) لفحص كثافة المضلعات.
  - شبكة أرضية ديناميكية لانهائية (Infinite Dynamic Grid).
  - استوديو إضاءة ثلاثي النقاط مع ظلال حقيقية وخلفيات بيئية تفاعلية.

### 3. محرك العمليات البوليانية (CSG Engine)
- مدعوم بمكتبة `three-bvh-csg` لتطبيق عمليات الجمع (Union)، الطرح (Subtract)، والتقاطع (Intersect) على المجسمات ثلاثية الأبعاد في أجزاء من الثانية.
- **ميزة تقطيع الثنائيات (Octant Slicing)**: تقطيع أي مجسم إلى 8 قطاعات هندسية متوازنة لفحصه قطاعياً أو طباعته على أجزاء مجزأة.

### 4. المصمم المساعد بالذكاء الاصطناعي
- يفهم الأوامر النصية باللغتين **العربية** و **الإنجليزية**؛ مثل: *"ترس ميكانيكي بـ 10 أسنان"* أو *"شعار نجمة بـ 6 رؤوس"* أو *"لوحة إلكترونية بأبعاد 100x50x5 مم"*.
- استخراج تلقائي للأبعاد الواقعية بالمليمتر وضبط مقياس المجسم وفقاً للمعايير الصناعية.

### 5. تصدير مباشر للطباعة ثلاثية الأبعاد
تصدير بنقرة زر واحدة دون الحاجة لتثبيت برامج وسيطة:
- **`STL`**: الصيغة العالمية الأولى لطابعات FDM و Resin (جاهزة لبرامج Bambu Studio و Cura و PrusaSlicer).
- **`GLB`**: صيغة الويب والألعاب خفيفة الوزن مع المواد والألوان.
- **`OBJ`**: صيغة البرامج الهندسية (Blender, Maya, 3ds Max).
- **`SVG`**: مسار متجهي لماكينات القطع بالليزر (Laser Cutters / CNC).
- **`PNG`**: لقطة شاشة عالية الدقة بدون خلفية للاستعراض.

## 🏗 معمارية النظام

```text
[ كاميرا الويب العادية ]
         ↓
[ محرك MediaPipe للرؤية العصبية (GPU WASM) ]
         ↓
[ استخراج 21 إحداثية ثلاثية الأبعاد في الفضاء ]
         ↓
[ محلل الإيماءات الهندسية (قرصة، قبضة، يد مفتوحة) ]
         ↓
[ منعم المسارات (Catmull-Rom Spline) + المصنف البارامتري ]
         ↓
[ محرك العمليات البوليانية (three-bvh-csg) ]
         ↓
[ مستعرض ومصيّر Three.js / React Three Fiber ]
         ↓
[ التصدير النهائي المباشر: STL / GLB / OBJ / SVG ]
```

## ✋ دليل إيماءات وحركات اليد

| الحركة | شروط التحقق الهندسية | الوظيفة الأساسية في الاستوديو |
| :---: | :--- | :--- |
| **`القرصة (PINCH)`** | تقارب طرف الإبهام والسبابة لأقل من 34% من قطر الكف | **الرسم والبثق ثلاثي الأبعاد**: بدء خط هندسي في الهواء. |
| **`القبضة (GRAB)`** | انثناء 3 أصابع أو أكثر للداخل مع ثبات الإبهام | **التحريك والسحب (Translate)**: تحريك المجسم في الفضاء. |
| **`اليد المفتوحة (OPEN)`** | امتداد كافة الأصابع الخمسة بالكامل | **التدوير وفحص المشهد (Orbit Rotate)**: تدوير زاوية الكاميرا. |
| **`الوضعية الحرة (IDLE)`** | اليد في وضع الراحة الطبيعي | **المؤشر الليزري ثلاثي الأبعاد**: توجيه المؤشر دون إطلاق رسم. |

## 💻 خطوات التشغيل المحلي

### المتطلبات الأساسية
- مثبت **Node.js** بإصدار `20.x` أو أحدث.
- مدير حزم مثل `npm` أو `pnpm` أو `yarn`.
- كاميرا ويب عادية.

### خطوات الإعداد السريع
```bash
# 1. استنساخ المشروع من جيت هاب
git clone https://github.com/mahmoudmma667-gif/flowx-3d.git
cd flowx-3d

# 2. تثبيت الحزم والمكتبات
npm install

# 3. إعداد ملف البيئة
copy .env.example .env

# 4. توليد قاعدة البيانات
npx prisma generate
npx prisma db push

# 5. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000` وامنح المتصفح إذن الوصول للكاميرا للبدء.
